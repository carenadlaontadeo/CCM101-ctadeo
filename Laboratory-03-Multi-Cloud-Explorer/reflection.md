# Mission Reflection

After completing the Multi-Cloud Explorer laboratory activity, the cloud platform that impressed me the most is Amazon Web Services (AWS). I was impressed by the wide range of services it provides for computing, storage, networking, databases, and other cloud needs. However, I also learned that Microsoft Azure and Google Cloud Platform (GCP) have their own strengths and can be more suitable depending on the requirements of an organization.

AWS, Azure, and GCP have many similarities because all three are major public cloud platforms that provide services such as virtual machines, storage, networking, databases, identity management, and other cloud solutions. They also provide scalable resources and global infrastructure that organizations can use to deploy and manage applications. Although their services may have different names and features, they solve many similar business and technical needs.

I learned that business requirements are very important when selecting a cloud platform. An organization should consider its existing technologies, budget, workload, scalability requirements, and specific goals. For example, Microsoft Azure can be a suitable choice for an organization that already uses Microsoft technologies, while GCP can be a strong option for organizations focused on Artificial Intelligence, Machine Learning, and Kubernetes.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about selecting the most popular platform. A cloud solution should be based on the client's actual needs and should provide a practical solution to its problems. I also learned how to compare services and explain why a particular platform may be appropriate for a specific business scenario.

Finally, my GitHub Cloud Computing Portfolio improved because I added organized research, comparison tables, client recommendations, Linux investigation results, screenshots, and a reflection. This activity helped me practice technical documentation using Markdown and improved my understanding of how cloud platforms can be evaluated based on real-world business requirements.
