# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform that provides cloud services for computing, storage, networking, databases, security, analytics, and application development. It allows organizations to deploy and manage applications and infrastructure through Microsoft's cloud environment.

## Global Infrastructure

Azure provides a global infrastructure organized into geographic regions and availability infrastructure. Organizations can select appropriate Azure regions when deploying resources to help improve availability, performance, and resilience.

## Cloud Management Console

The Microsoft Azure Portal is a web-based management console used to create, configure, monitor, and manage Azure resources. It provides a unified interface for managing services such as virtual machines, databases, virtual networks, and storage.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide scalable virtual computing resources that allow organizations to run applications and operating systems in the cloud.

### 2. Azure Blob Storage

Azure Blob Storage provides object storage for large amounts of unstructured data such as documents, images, videos, and application files.

### 3. Azure Virtual Network

Azure Virtual Network allows Azure resources to communicate with each other, on-premises networks, and the internet through a private cloud network.

### 4. Microsoft Entra ID

Microsoft Entra ID provides identity and access management for users, applications, and resources. It helps organizations control authentication and access to cloud resources.

## Three Advantages

1. **Microsoft integration** – Azure works closely with Microsoft technologies and services used by many organizations.
2. **Hybrid cloud capabilities** – Azure provides tools for connecting and managing cloud and on-premises environments.
3. **Scalability** – Azure resources can be scaled according to application and business requirements.

## Typical Enterprise Use Cases

Enterprises can use Azure for hosting business applications, running Windows and Linux virtual machines, storing organizational data, managing identities, supporting hybrid environments, developing applications, and implementing backup and disaster recovery solutions.
