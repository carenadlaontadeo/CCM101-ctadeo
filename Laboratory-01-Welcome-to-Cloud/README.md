# Laboratory 01 - Welcome to the Cloud

## Mission Overview
This laboratory activity served as the onboarding mission for a Junior Cloud
Infrastructure Engineer Trainee at CloudNova Technologies, focusing on Linux
fundamentals, documentation, and GitHub portfolio setup.

## Objectives
- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a professional GitHub repository.
- Document technical work using Markdown.

## Activities Performed
- Created a new user with sudo privileges and logged in.
- Investigated system information (distro, kernel, CPU, memory, disk).
- Built a folder structure inside the home directory.
- Created and pushed a GitHub portfolio repository.

## Linux Commands Used
- adduser, usermod, su, whoami, pwd, hostname
- lsb_release -a, uname -r, lscpu, free -h, df -h
- mkdir, cd, nano, ls, cat

## Skills Learned
- Basic Linux user and system administration.
- Navigating and organizing the Linux file system.
- Writing technical documentation using Markdown.
- Creating and managing a version-controlled GitHub repository.
