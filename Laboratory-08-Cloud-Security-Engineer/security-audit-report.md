# Security Audit Report

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means that users and applications should only receive the permissions they need to perform their tasks. This helps protect cloud accounts by limiting unauthorized access and reducing the possible damage if an account is compromised.

## 2. Attack Surface

The attack surface refers to all the points where an attacker could try to access or exploit a virtual machine. Open ports, running services, and unnecessary applications can increase the attack surface, so reducing them helps improve server security.

## 3. Default Deny Policy

A Default Deny policy blocks incoming network traffic unless it is explicitly allowed by a firewall rule. It is safer than trying to block individual hackers because unknown or unauthorized connections are also blocked by default.
