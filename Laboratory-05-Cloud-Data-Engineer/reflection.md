# Mission Reflection

This laboratory activity helped me understand how object storage can be used to manage large amounts of data in a cloud environment. Object Storage is better suited for storing millions of photos because it is designed for unstructured data such as images, videos, and backups. Unlike a traditional block storage hard drive, object storage can organize large numbers of files as objects and is appropriate for applications that need to store and access many user-uploaded images.

Using Docker made it easier to deploy the MinIO storage server because the server could be started as a container using a Docker command. Instead of manually installing and configuring the storage software, Docker provided a consistent environment where MinIO could run with the required ports and environment variables. This made the deployment process more organized and easier to manage.

A bucket in cloud storage is a storage container where objects or files are stored. In this activity, I created a bucket named `client-photos` and uploaded a sample file into it. This demonstrated how files can be organized within an object storage system.

Large enterprise companies can help prevent data loss by keeping copies of their data and using backup and redundancy strategies. If a physical server crashes, additional copies or replicated data can help the organization recover its stored information.

My confidence in navigating the Linux command line is also growing. Through this activity, I practiced using Docker commands in the KillerCoda Ubuntu Playground and learned how commands can be used to deploy and verify a cloud storage service. I became more comfortable working with the terminal and understanding the results of the commands I entered.
