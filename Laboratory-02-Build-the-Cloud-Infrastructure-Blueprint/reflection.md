# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I think networking is one of the most important cloud infrastructure components because it connects users, servers, applications, and other cloud resources. Without networking, users would not be able to access cloud services through the internet. Networking also allows different cloud resources to communicate with each other.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a stable and flexible operating system for servers and cloud workloads. It provides command-line tools that allow administrators to manage processes, storage, networking, users, and applications. During this laboratory activity, I used Linux commands to investigate the KillerCoda cloud server and identify its infrastructure resources.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it provides clear information about the planned infrastructure before deployment. It helps engineers understand the available resources, system configuration, and relationships between different components. Good documentation can also reduce mistakes and make troubleshooting and future maintenance easier.

During this laboratory activity, I learned how to investigate a Linux server using commands such as `lscpu`, `free -h`, `df -h`, and `ip addr`. I also learned how to identify compute, storage, networking, and operating system resources in a cloud environment. In addition, I improved my Markdown documentation skills and learned how to compare equivalent services from AWS, Microsoft Azure, and Google Cloud Platform.
