# Mission Reflection

Throughout the Cloud Computing laboratory activities, I learned how cloud technologies work together to manage applications, data, and infrastructure. Automation is critical when managing hundreds of cloud servers because it saves time, reduces repetitive manual work, and minimizes human errors. Instead of manually performing the same tasks on every server, administrators can use scripts to execute tasks consistently and efficiently.

However, automation also has potential dangers. A destructive typo in a script scheduled to run on 1,000 servers could delete important files, interrupt services, or cause major system failures across many servers. This shows that automation must be used carefully. Scripts should be tested, reviewed, and monitored before they are deployed in production environments.

Writing a Bash script was different from creating a Docker Compose YAML file in Mission 6. A Bash script contains commands that execute tasks step by step, such as creating directories and compressing files for backups. In contrast, a Docker Compose YAML file defines and configures the services required to run an application using containers. Both support automation, but they serve different purposes in cloud operations.

From Laboratory 1 to Laboratory 9, my understanding of Cloud Computing developed from learning basic cloud concepts to exploring infrastructure, multi-cloud environments, containerization, data storage, application deployment, cloud operations, security, and automation. These activities helped me understand that cloud computing involves more than simply storing files online. It also requires managing resources, protecting systems, deploying applications, monitoring performance, and automating repetitive tasks.

The role I enjoyed the most was the Cloud Automation Engineer because I learned how to write a Bash script, create compressed backups, manage file permissions, and schedule tasks using Cron. I found it interesting that commands can be combined to perform important tasks automatically without requiring someone to execute them manually every time.

Overall, these laboratory activities improved my technical knowledge and confidence in using Linux commands and cloud tools. I also learned that successful cloud operations require accuracy, security, testing, and proper documentation. I believe these skills will help me continue learning and prepare for future opportunities in the IT industry.
