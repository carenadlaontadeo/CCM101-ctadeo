# Automation Research

## 1. Bash Script

A Bash script is a file that contains Linux commands arranged to perform tasks automatically. The `#!/bin/bash` line, also called the shebang, tells the system to use Bash to interpret and execute the script.

## 2. Variables

Variables are used to store information, such as folder paths, that a script needs to use. For example, `$BACKUP_DIR` allows us to reuse the backup folder's name without typing its full path repeatedly, making the script easier to read and update.

## 3. Cron Job

A cron job is a scheduled task in Linux that runs commands or scripts automatically at a specified time. It is essential in cloud operations because it helps administrators automate repetitive tasks, such as backups, and reduces the need for manual work.
